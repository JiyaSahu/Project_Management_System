Project Management System

A comprehensive system designed to streamline project workflows by integrating SDLC models like Waterfall and Agile. This system includes features for task management, team collaboration, progress tracking, and role-based access control.

🚀 Features

Task Management: Create, assign, and track project tasks efficiently.

Team Collaboration: Work seamlessly with team members.

Progress Tracking: Implemented dynamic Gantt charts for visual project tracking.

SDLC Integration: Supports multiple models like Waterfall & Agile.

Role-Based Access Control: Secure user authentication and permissions.

🛠 Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: C# with .NET Framework

Database: MySQL

Design: Figma

🎯 Responsibilities

🛠 Installation

Clone the repository:

git clone https://github.com/JiyaSahu/project-management-system.git
cd project-management-system

Setup MySQL Database:

Import the provided SQL file.

Update the database connection string in the .NET backend.

Run the Project:

Open the solution in Visual Studio.

Build and run the project.

📌 Usage

Sign up/Login to access the dashboard.

Create a new project and select an SDLC model.

Assign tasks to team members.

Track progress using the Gantt chart.

Manage roles & permissions for secure access.
